# Project Documentation

For this project, our team uses the **JSDoc CLI** to automatically generate developer documentation.

The source of the documentation comes from JavaScript files located in the `source/` directory. Output is generated into this `docs/` folder.

Documentation is kept up to date through **GitHub Actions**, which regenerate the files on every push to the `main` branch. This ensures the documentation always reflects the current state of the codebase.

> Do not edit the contents of this folder manually. Any changes will be overwritten the next time documentation is generated.
