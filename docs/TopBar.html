Class: TopBar

TopBar()

Custom Web Component representing the horizontal top bar. Comes with five iconic buttons: Home, Save, Download, Share, and Profile. Basically, everything you need to look productive without doing much.

Constructs the top bar, loads external CSS, creates five beautifully generic buttons, and shoves it all into Shadow DOM.
